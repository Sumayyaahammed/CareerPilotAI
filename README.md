# CareerPilot AI

An Agentic AI-powered career guidance platform that helps students and job seekers identify career paths and improve their skills.

## Features

- Resume Analysis
- Career Recommendation
- Skill Gap Analysis
- AI Career Chat
- Learning Roadmap

## Technologies

- Python
- Streamlit
- FastAPI
- LangChain
- LangGraph
- FAISS
- Scikit-Learn
